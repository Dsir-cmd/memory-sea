# 截图

**规则：这里每一张图都必须来自假数据。**

真实记忆一旦进了截图，就跟着 commit 永久留在历史里了——比误传数据库更难收回，
因为图片不会被 `verify` 扫出来。

## 怎么拍

```bash
# 1. 造一份假库（50 条虚构记忆 / 3 个会话 / 半年跨度）
npm run demo

# 2. 让插件读它：把 config.example.json 复制成插件目录下的 data/config.json，
#    把 dbPath 改成指向 demo/livingmemory.db 的绝对路径

# 3. 重启 DSH，点开左侧「记忆海」

# 4. 截图，存到这里
```

## 需要哪几张

| 文件 | 内容 | 用途 |
|---|---|---|
| `sea.png` | 记忆海全景（含脑区、点、线） | README 头图、社交平台首图 |
| `detail.png` | 选中一条记忆，右侧详情 + 相似记忆 | 展示"能查到" |
| `list.png` | 列表视图 + 检索结果 | 展示"不只好看" |
| `empty.png` | 没找到库时的引导 | 文档用，说明不会白屏 |

## 命名与压缩

- PNG，宽度 1600–2000 为宜，单张控制在 1MB 以内
- 深色主题优先（记忆海在深色下好看很多）
- 不要裁剪成正方形——社交平台九宫格会吃内容
